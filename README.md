#  Machine Learning Models: Regression & Classification

##  Overview

This repository contains implementations of fundamental **machine learning models** used for prediction and classification tasks. It covers both regression and classification techniques, along with model evaluation using train/test splits.

The goal of this project is to demonstrate practical understanding of core machine learning concepts and workflows.

---

##  Models Implemented

### 🔹 Regression Models

* **Linear Regression**
* **Multiple Linear Regression**
* **Polynomial Regression**

- Used for predicting continuous values (e.g., price, income, sales)

---

### 🔹 Classification Models

* **Logistic Regression**

- Used for predicting categorical outcomes (e.g., Yes/No, Approved/Rejected)
